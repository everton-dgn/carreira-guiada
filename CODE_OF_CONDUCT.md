# Código de conduta

Este projeto recebe pessoas com diferentes experiências técnicas e profissionais.
Trate dúvidas com respeito. Críticas devem falar da proposta ou do comportamento,
sem atacar a pessoa.

São esperados: linguagem respeitosa, explicações úteis, abertura para correções
e cuidado com dados pessoais. Não são aceitos assédio, discriminação, ameaças,
insultos, divulgação de informações privadas ou publicidade repetitiva.

O código vale em issues, pull requests, discussões e outros espaços oficiais.
Moderadores podem remover conteúdo, limitar participação ou bloquear contas
conforme a gravidade e a repetição, explicando a decisão quando possível.

Para denunciar, use as ferramentas de denúncia do GitHub na interação afetada.
Não reproduza publicamente dados privados como prova. Vulnerabilidades técnicas
devem seguir [SECURITY.md](SECURITY.md).

Este código é próprio do projeto. Não exige vínculo profissional, nível de
experiência ou concordância com uma proposta para participar.
